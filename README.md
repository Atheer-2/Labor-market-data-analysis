# Labor-market-data-analysis
Labor market data analysis using MySQL and Excel, including data cleaning, regression analysis, forecasting, and visualization.

This project analyzes World Bank (WDI) labor market indicators from 2000 to 2024 for Saudi Arabia, India, and Sudan: GDP growth, unemployment rate, and labor force participation rate.

Files:                                                                                                                                                                  
Database_clean_labor_market_3_countries.sql: MySQL data cleaning script.                                                                             
Labor_market_backup.sql: final cleaned database.                                                                                                               
Excel file: regression, forecasting, and charts.

Notes: Sudan’s GDP growth is missing for 2022 to 2024.
